# Prototype Status and Honest Claims

## What is included

A static browser prototype in `prototype/index.html`, designed to demonstrate synthetic application routing, deficiency returns/resubmission, a configurable demo automation cycle, repeated-cycle idempotency, EVC scheduling/report state, compliance evidence submission and verification, document expiry/renewal review, alert acknowledgement, and audit history.

## What is not included

No server API, production user authentication, server-side role/permission enforcement, shared database, secure document store, real email/SMS delivery, background worker, official AICTE-system integration, actual document authenticity verification, or AI-driven regulatory decisions.

## Before claiming more

Implement each production capability, write tests, run them, capture verification evidence, and update this page. A UI control, a stubbed endpoint, or a generated alert entry does not prove external delivery or secure processing.


## Full-stack target (not yet claimed as implemented)

The next implementation phase is defined in `docs/PRODUCTION_IMPLEMENTATION_BLUEPRINT.md`. It requires a backend API, provider-verified authentication, server-side role and record-scope authorization, shared PostgreSQL persistence, migrations/seed/reset commands, durable idempotent automation worker, transactionally correlated audit/outbox records, connected frontend, tests, and deployment/setup instructions. This is a build target, not a statement that those components already exist in the HTML prototype.
